# 量化交易终端（A 股）

从实时监控到策略研究、回测验证、模拟盘交易的**一体化本地量化平台**。深色投研界面，五大视图：

```
实时监控 ──→ 策略回测 ──→ 策略对比 ──→ 因子挖掘 ──→ 模拟盘
 (行情/信号)   (历史验证)    (横向择优)    (IC/分组)   (时间轴前推)
```

## 五大视图

### 1. 实时监控
自选股实时行情（WebSocket 推送，5 秒级）、Canvas K 线（分时/30分/60分/日K）、12 条技术信号流、全市场涨跌分布、行业板块文字总结和涨跌幅榜。

### 2. 策略回测
左侧配置 → 右侧出结果，约 1 秒完成：
- **5 个内置策略**：信号评分选股（复用监控台 12 规则）、双均线交叉、动量轮动、布林带均值回归、MACD 趋势，参数可调
- **4 个股票池**：沪深300 / 中证500 / 全A（剔除ST与北交所）/ 我的自选
- **真实交易约束**：T+1、开盘价成交、涨停买不进/跌停卖不出、一字板过滤、100 股整手、单日成交量占比上限（冲击成本）
- **成本模型**：佣金（万2.5、最低5元）+ 过户费 + 印花税（卖出）+ 滑点，全部可调
- **风控**：单票上限、个股止损、移动止损、组合回撤熔断（触发减仓 50%，暂停 20 日后自动恢复）
- **4 种权重**：等权 / 按分数 / 波动率倒数 / 风险平价
- **12 项绩效**：总收益、年化、超额、夏普、索提诺、最大回撤、卡玛、胜率、盈亏比、Alpha/Beta、年化换手
- **图表**：净值+基准+回撤三合一曲线、交易流水、期末持仓

### 3. 策略对比
一键批量回测全部策略（同一股票池/区间/成本），净值曲线叠加 + 绩效排名表。结果缓存 1 小时。

### 4. 模拟盘（纸上交易）
- 选择策略与股票池创建账户（默认 100 万），**不接券商、不动真金**
- 「执行今日调仓」：用最新数据生成信号 → 按目标权重下单 → 现价撮合（含滑点费用）
- 个股止损/移动止损每日自动检查
- 账户、持仓、流水、每日净值全部落盘（`data/paper/state.json`），跨重启恢复
- 与回测共用同一套成本/风控模型，保证「回测 → 模拟」一致性

### 5. 量化因子挖掘
- 使用全 A 股近一年日线，评估 20 日动量、5 日反转、20 日波动率、成交量活跃度、价格偏离均线
- 以当日收盘因子值预测未来 5 个交易日收益，按截面 Spearman IC、年化 ICIR、IC 正向比例和因子分组收益排序
- 使用当前可用股票和未复权行情，可能存在幸存者偏差及公司行为影响；结果用于研究分析，不代表未来表现或投资建议

## 快速开始

```bash
cd quant_monitor
python3 -m pip install -r requirements.txt
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000
# 浏览器打开 http://localhost:8000
```

首次使用建议：先在「策略回测」选股票池点运行（数据自动下载，沪深300 约 20 秒），再到「模拟盘」创建账户。

### 全市场近一年日线数据

应用每次启动时会在后台检查全市场 A 股日线：首次为每只股票获取近一年数据，之后补入近期缺失日线；同一天已成功更新过的数据不会重复下载。数据独立保存到 `data/daily_a/`，不会覆盖现有 `data/kline/` 等静态数据。自动补齐失败会记录在应用日志和数据清单中。

```bash
python3 -m data.update_daily_a
```

也可以手动执行以上命令；每只股票的数据按 `data/daily_a/{代码}.json` 保存，`manifest.json` 记录更新时间、覆盖日期、股票名称和失败代码。`--workers` 可调整并发数（最大 16）。

## 项目结构

```
quant_monitor/
├── app/
│   ├── market.py        # 行情数据层（腾讯快照 + 新浪K线/榜单，多源降级）
│   ├── factor_mining.py # 全市场技术因子 IC/ICIR 与分组收益评估
│   ├── indicators.py    # 指标库（SMA/EMA/MACD/RSI/BOLL/KDJ/ATR）+ 信号规则 + Precomputed 预计算
│   ├── engine.py        # 实时监控引擎（轮询线程 + WebSocket 推送）
│   ├── config.py        # 成本/风控/回测参数 + 策略元信息（集中配置）
│   ├── universe.py      # 股票池构建 + K线磁盘缓存 + 批量下载
│   ├── strategies.py    # 5 个内置策略（统一 score() 接口，无未来函数）
│   ├── backtest.py      # 事件驱动回测引擎（T+1/涨跌停/成本/风控/熔断）
│   ├── performance.py   # 绩效指标（夏普/卡玛/Sortino/Alpha-Beta/月度收益）
│   ├── compare.py       # 多策略批量对比
│   ├── paper.py         # 模拟盘账户（状态持久化、每日调仓、撮合）
│   └── main.py          # FastAPI 路由（REST + WebSocket）
├── static/              # 前端（原生 JS + Canvas，零框架）
│   ├── app.js           # 监控视图
│   └── trading.js       # 回测/对比/模拟盘视图
└── data/                # 日线补齐程序与数据；原有 watchlist.json / kline/ / universe/ / paper/ 保留
```

## 主要 API

| 接口 | 说明 |
|---|---|
| `GET /api/snapshot` `/ws` | 监控快照 / 实时推送 |
| `GET /api/strategies` | 策略与股票池元信息 |
| `GET /api/universe/{kind}` | 股票池成员（含缓存状态） |
| `POST /api/universe/{kind}/download` | 批量下载日线 |
| `POST /api/backtest` | 运行回测（参数JSON） |
| `POST /api/compare` | 多策略对比 |
| `GET /api/sectors/summary` | 行业板块文字总结与涨跌详情 |
| `GET /api/factors/mine?horizon=5` | 全 A 技术因子挖掘（支持 5/10/20 个交易日） |
| `GET /api/paper` · `POST /api/paper/init` `/run` `/reset` | 模拟盘查询/创建/执行/重置 |

## 回测可信度设计

- **无未来函数**：t 日收盘数据算信号，t+1 日开盘成交
- **信号预计算**：指标序列一次性算好逐日查表（沪深300 全池 3 秒内）
- **熔断不解仓**：触发熔断只减仓 50% 并暂停建仓 20 日，不会把组合冻死在峰值（避免净值曲线人为美化）
- **诚实提醒**：默认参数下多数技术策略跑不赢沪深300，这是正常现象——回测的价值在于排除无效策略
